# 🌐 Personal Portfolio

This repository contains the source code for my personal portfolio website.

The goal of this project is to present who I am, my background in Software Engineering, and the projects I’ve worked on, in a clean and accessible way.

🔗 **Live website:** https://eduardofreitasf.github.io/portfolio/

## 🧩 Features

- Responsive single-page layout
- Animated sections on scroll
- Hero section with personal introduction and links
- About Me, Projects, Education, and Contact sections
- Direct access to CV (PDF)
- Clean, light theme with subtle contrast
- Built with modern frontend tooling
